A "Purist-Classic" tactical puzzle game with a modern "Dark Tech" aesthetic.

## Game Overview
Tetris-Vibe challenges players with a high-precision, no-assist environment. It features **True Random** piece generation and **Strict Rotation** (no wall-kicks), rewarding pure skill and spatial planning.

### Core Features
- **Daily Shift System**: A global daily seed ensures all players face the exact same piece sequence for shared competition.
- **Dark Tech Aesthetic**: Deep neon-on-black visuals with a cyber-industrial atmosphere.
- **Elastic Physics**: Tactile "thud" and screen-shake effects that scale with difficulty.
- **Zero Assistance**: No hold, no undo, no guide rails. Just you and the grid.

### Controls (Keyboard)
| Action | Key |
|:---|:---|
| **Move** | Left / Right Arrows |
| **Rotate CW** | Up Arrow / X |
| **Rotate CCW** | Z |
| **Soft Drop** | Down Arrow |
| **Hard Drop** | Space Bar |
| **Pause** | Esc / P |


## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Run Tests
```bash
# Run unit tests
npm run test

# Run tests with coverage
npm run test:cov
```
